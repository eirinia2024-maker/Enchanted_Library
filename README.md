# Wordlore

Локальная витрина мини-игр для изучения английского языка.

## Запуск

Требуется Node.js 22 или новее.

```powershell
npm install
npm run dev
```

После запуска откройте `http://localhost:3000`.

## Производственная проверка

```powershell
npm run build
npm start
```

Проект рассчитан на самостоятельный локальный запуск.
