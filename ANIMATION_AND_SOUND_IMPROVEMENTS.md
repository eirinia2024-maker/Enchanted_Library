# Animation and Sound Improvements

Цель: сохранить текущую механику игр, но сделать вторую и третью игру более живыми за счет реакций персонажей, микродвижений, эффектов переходов и более выразительных звуков. Изменения должны быть локальными, без новых хостинговых зависимостей и без тяжелых библиотек.

## Текущее состояние проекта

- Вторая игра находится в `app/AlchemyWordGame.tsx`, стили - в блоках `/* Alchemist word game */` и `/* Alchemist word game redesign */` в `app/globals.css`.
- Третья игра находится в `app/LibraryLabyrinthGame.tsx`, стили - в блоке `/* Library Labyrinth */` в `app/globals.css`.
- Общая музыка и синтезированные игровые звуки уже собраны в `app/GameAudio.tsx`.
- Вторая игра уже использует состояния `idle`, `pour`, `fire`, `success`; это хорошая точка входа для реакций алхимика.
- Третья игра уже использует состояния `book`, `topic`, `question`, `routes`, `ghost`, `failed`, `final`; их удобно использовать как триггеры для анимаций.

## Вторая игра: Words Potion

### Проблема

Сейчас алхимик находится внутри фоновой картинки `alchemist-word-lab-v1.png` и не меняется при действиях игрока. Пробирки, огонь и буквы уже реагируют, но главный персонаж остается статичным, поэтому экран выглядит менее живым, чем задумано.

### Что нужно добавить

1. Реакции алхимика:

- `idle`: легкое дыхание, едва заметное покачивание шляпы/бороды, периодическое моргание.
- `letterCorrect`: алхимик довольный, чуть наклоняется к котлу или приподнимает руку.
- `letterWrong`: испуг или недовольство, быстрый shake, вспышка света от котла.
- `wordComplete`: радостная реакция, искры вокруг рук, короткий жест "заклинание получилось".
- `gameLost`: усталый/растерянный алхимик, дым или пар перед ним.
- `gameWon`: торжественная поза, мягкое золотое свечение.

2. Технический вариант реализации:

- Не менять весь фон лаборатории на каждый кадр. Лучше добавить поверх фона отдельный слой персонажа: `alchemy-wizard-layer`.
- Подготовить 4-6 прозрачных PNG-ассетов алхимика в том же стиле и ракурсе:
  - `alchemy-wizard-idle.png`
  - `alchemy-wizard-happy.png`
  - `alchemy-wizard-wrong.png`
  - `alchemy-wizard-casting.png`
  - `alchemy-wizard-win.png`
  - `alchemy-wizard-tired.png`
- Разместить слой поверх существующего фона, примерно в центральной верхней зоне, чтобы он совпадал с текущим алхимиком на фоне.
- В `AlchemyWordGame.tsx` добавить состояние реакции, например `wizardReaction`, и менять его внутри `chooseLetter`.
- Для коротких реакций использовать таймеры 600-1200 мс, после чего возвращать `idle`.
- Для `prefers-reduced-motion` оставлять смену позы без покачивания и тряски.

3. Если отдельные ассеты рисовать не хочется:

- Можно сделать быстрый первый этап только CSS-анимацией на маске/слое: glow, blinking sparkle, shake на ошибке, pulse на успехе.
- Но лучший визуальный результат даст именно прозрачный PNG-персонаж поверх фона.

### Дополнительные анимации для Words Potion

- При выборе темы: карточка темы вспыхивает цветом темы, потом экран мягко переходит в лабораторию.
- При правильной букве: капля летит не просто из центра, а от выбранной пробирки к котлу.
- При неправильной букве: котел дает облако пара или огненную вспышку, прогресс букв исчезает с эффектом растворения.
- При завершении слова: буквы на котле подпрыгивают по очереди слева направо.
- При победе: финальный экран появляется через золотую дымку, не мгновенно.

### Звуки для Words Potion

Использовать текущий `useGameAudio`, расширив `GameSound`:

- `wizardHappy`: короткий звонкий магический аккорд.
- `wizardWrong`: низкое "бух" с шипением.
- `wordComplete`: арпеджио вверх.
- `steam`: шумовой шипящий эффект через Web Audio noise buffer.
- `topicSelect`: мягкий книжный перелист + sparkle.

Важно: звуки должны подчиняться текущей громкости и mute из `GameAudioControls`.

## Третья игра: Library Labyrinth

### Проблема с меню выбора темы

Сейчас плашки тем на свитке могут быть шире визуальной области свитка. Особенно заметно из-за длинного названия `There is / are` и текущего `width: 100%` у `.labyrinth-topic-list` внутри компактного `.labyrinth-scroll-content`.

### Как поправить меню

1. Ограничить список тем внутри свитка:

- `.labyrinth-topic-list { width: min(100%, 360px); box-sizing: border-box; }`
- `.labyrinth-topic-list button { width: 100%; box-sizing: border-box; min-width: 0; }`

2. Сделать текст переносимым:

- `.labyrinth-topic-list strong { overflow-wrap: anywhere; }`
- `.labyrinth-topic-list small { white-space: normal; line-height: 1.15; }`

3. Для маленьких экранов:

- уменьшить вертикальные gaps;
- уменьшить padding кнопок;
- сделать заголовок выбора темы короче или с меньшим `font-size`;
- если высоты не хватает, разрешить внутренний scroll только у списка тем, а не у всего игрового окна.

## Анимации для Library Labyrinth

### Книга

- В состоянии `book`: постоянное мягкое свечение вокруг книги.
- При hover/focus: книга слегка приподнимается, свет становится теплее.
- При клике: короткая вспышка и эффект раскрытия перед появлением свитка.
- Звук: `bookOpen`, можно расширить текущий `book`.

### Свиток и вопросы

- При появлении свитка: `scrollUnroll`, масштаб от 0.94 до 1, opacity 0 -> 1.
- При правильном ответе: зеленовато-золотая окантовка, маленькие искры по краям.
- При неправильном ответе: уже есть `is-dissolving`; усилить эффект частицами/дымкой и звуком `spellDissolve`.
- При смене вопроса после ошибки: старый текст растворяется, новый появляется с легким blur-in.

### Стрелки маршрута

- В состоянии `routes`: стрелки должны пульсировать не синхронно, чтобы игроку было ясно, что они кликабельны.
- При hover: усиление свечения и короткий "trail" за стрелкой.
- При клике по правильной стрелке: экран затемняется по краям, появляется эффект движения вперед/в сторону.
- При клике по неверной стрелке: короткий тревожный всплеск, затем переход в тупик.

### Переходы между локациями

- Добавить класс перехода, например `is-transitioning`.
- На 350-550 мс затемнять сцену и слегка увеличивать фон (`scale(1.02)`), затем менять `location` и возвращать нормальный вид.
- Для движения вперед использовать вертикальный light streak по центру.
- Для движения влево/вправо использовать сдвиг света в выбранную сторону.

### Призрак волшебника

- В состоянии `ghost`: плавное появление снизу, дрожащий glow, легкое покачивание.
- Текстовое сообщение уже анимировано через `ghostMessage`; добавить синхронное мерцание на фон или на силуэт.
- Звук: `ghostAppear`, низкий воздушный тон + тихий shimmer.

### Финал

- В treasure room: монеты/искры должны мерцать поверх фоновой картинки.
- При открытии финального свитка: короткий triumphant sparkle.
- Кнопки финала оставить читаемыми, но добавить hover-свечение в стиле золотой магии.

## Звуки для Library Labyrinth

Расширить `GameAudio.tsx` новыми типами:

- `scrollOpen`: шелест пергамента через быстрый noise envelope.
- `routeReveal`: мягкий магический подъем.
- `stepForward`: короткий whoosh.
- `deadEnd`: низкий удар + затухание.
- `ghostAppear`: воздушный призрачный тон.
- `treasure`: победный звон монет/колокольчиков.

Для простого внедрения можно оставить Web Audio синтез, как сейчас. Если позже захочется более "киношный" звук, можно добавить короткие mp3/wav в `public/assets/sfx/`, но на первом этапе это не обязательно.
